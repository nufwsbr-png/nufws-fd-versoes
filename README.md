# NUFWS F&D: instaladores

Este repositório guarda só os instaladores do aplicativo NUFWS F&D. O código fica em outro lugar.

## Instalar num computador

1. Abra a versão mais recente em **Releases** (à direita) e baixe o arquivo `nufws-fd-<versão>-setup.exe`.
2. Abra o arquivo baixado. Como o app não tem assinatura digital, o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Na primeira vez, o app pede três coisas: a pasta dos clientes no OneDrive, a sua conta (ou criar uma) e conectar o Claude com a conta do escritório.

## Atualizações

O app procura versões novas aqui sozinho. Quando há uma, ele baixa em segundo plano e mostra **Atualização pronta** na barra lateral. Um clique fecha o app, instala e abre de novo. Ele nunca instala com um trabalho em andamento.
